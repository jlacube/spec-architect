# C001-TC-621 — portability dogfood (manual)

Verifies C001-TS-621 (C001-AC-617.1, C001-REQ-617): an implementer agent that is not part of the
Architect plugin can start from the hand-off alone.

- **Executor:** P-01 supervises (dogfood change of C001-T-074).
- **Environment:** REF-WIN with Claude Code and the Superpowers plugin installed; the Architect
  plugin disabled for this session.

## Procedure

1. Take an approved plan of a dogfood change (G3 approved), e.g. CHG-002 of C001-T-073.
2. Start a fresh Claude Code session in the repository with Superpowers enabled.
3. Send exactly: `execute the plan in .sdd/<NNN>-<slug>/20-plan/handoff.md`.
4. Observe the session until it starts its first task, without answering questions about where
   the tasks are.

## Pass when

- The session opens `handoff.md`, then the task file of the **first** entry of the Ordered task
  list, and starts that task.
- It asks no question about where the tasks, the spec or the reporting commands are (count
  questions tagged missing-info for C001-SC-04).

## Record

Date, Claude Code and Superpowers versions, the first task started, questions asked (verbatim),
pass/fail. Add the record to `docs/dogfood.md`.
