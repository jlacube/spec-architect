# C001-TC-1127 — `npm run check` in both shells on both Node versions (manual)

Verifies C001-NFR-401 (Windows 11, PowerShell 7 and Git Bash) through C001-TS-1118 (C001-AC-1117.1):
`npm run check` passes from the repository root in each shell with each supported Node version. The
same runs give the per-version test pass rate of C001-NFR-403 (C001-TC-1128).

- **Executor:** the implementer of C001-T-080 on REF-WIN; repeated by the implementer of C001-T-072 at
  the release commit.
- **Environment:** REF-WIN (Windows 11, git `core.autocrlf=true`); PowerShell 7 and Git Bash; Node
  20.20.2 and 22.22.3 installed through nvm-windows
  (`C:\Users\<user>\AppData\Local\Author Software\nvm\installs\v20.20.2` and `…\v22.22.3`); Claude Code
  reachable through `CLAUDE_CODE_EXECPATH` or `claude` on `PATH` (otherwise the `validate` step reports
  SKIP).
- **Repository state:** the measured commit, working tree clean apart from untracked `bench/results/`.

## Procedure

Run the four checks one after another, from the repository root, with nothing else running on the
machine (no test run, benchmark or build in parallel: the timing test C001-TC-705 and the coverage step
are sensitive to load).

1. **Git Bash, Node 20.20.2.** Put that Node first in `PATH` for this run only, then run the check and
   record the exit code and duration:

   ```bash
   export PATH="/c/Users/<user>/AppData/Local/Author Software/nvm/installs/v20.20.2:$PATH"
   node -v                     # must print v20.20.2
   start=$(date +%s); npm run check > check-bash-v20.log 2>&1; echo "exit=$? secs=$(( $(date +%s) - start ))"
   ```

2. **Git Bash, Node 22.22.3.** In a new Git Bash window (or with the 20.20.2 entry removed from
   `PATH`), the same with `v22.22.3`; `node -v` must print `v22.22.3`.
3. **PowerShell 7, Node 20.20.2.**

   ```powershell
   $env:PATH = "C:\Users\<user>\AppData\Local\Author Software\nvm\installs\v20.20.2;$env:PATH"
   node -v                     # must print v20.20.2
   $sw = [Diagnostics.Stopwatch]::StartNew(); npm run check *> check-pwsh-v20.log; "exit=$LASTEXITCODE secs=$([int]$sw.Elapsed.TotalSeconds)"
   ```

4. **PowerShell 7, Node 22.22.3.** In a new PowerShell window, the same with `v22.22.3`.

`nvm use` changes the Node version for every shell of the user; putting the install folder first in
`PATH` changes it for one shell only, which keeps the four runs independent.

## Record (in `docs/nfr-results.md` §2)

Per run: shell and version (`$BASH_VERSION`, `$PSVersionTable.PSVersion`), `node -v`, `npm -v`; the
step table printed under `=== npm run check ===` (PASS / FAIL / SKIP per step: typecheck, validate,
build, tests, fixtures, encoding, structure, targets, tarball, coverage); the test counts of the `tests`
step (`# tests`, `# pass`, `# fail`, `# skipped`); the scan totals of the `encoding` step; the line and
branch figures of the `coverage` step; the exit code; the duration. Name every failing or skipped test.

After the four runs `git status` must show no tracked change (the coverage step restores the shipped
bundles).

## Pass when

- `npm run check` exits 0 in all four runs.
- 100% of the run tests pass in each run; only POSIX-only tests are skipped (C001-NFR-403).
- The `encoding` step reports 0 violations in files written by the CLI and the `coverage` step reports
  ≥ 85% lines and ≥ 75% branches over `src/` in every run.
