# C001-TC-1102 — marketplace install on Windows 11 (manual, timed)

Verifies C001-TS-1102 (C001-AC-1102.1, C001-REQ-1102) and gives the timing of C001-NFR-602 (time to
first change ≤ 15 minutes).

- **Executor:** functional part: the implementer or conductor of C001-T-072 (automated); timed part:
  P-01 (or a P-03 adopter), with the README of C001-T-062.
- **Environment:** REF-WIN, an **isolated Claude profile** (C001-SPEC-NFR, "Isolated Claude profile";
  defect D-030, P-01 Q-clean-profile-01): in the tester's own Windows account, one PowerShell 7 window
  with every `CLAUDE*` / `ANTHROPIC*` variable removed and `CLAUDE_CONFIG_DIR`, `HOME`, `USERPROFILE`
  and `APPDATA` pointing into a new empty folder, set up by `scripts/manual/isolated-profile.ps1`.
  Claude Code ≥ 2.1.295 (the desktop-bundled binary; the script finds it) and Node ≥ 20 installed;
  this repository available as a local folder.
- **Caveat:** machine-wide tools (Node, Git, ripwire, uv, Serena) and `LOCALAPPDATA` stay those of the
  tester's account, so a prerequisite the README fails to mention does not show in this run.

## Functional part (automated, no model turn)

`node scripts/manual/isolated-profile-check.mjs <new empty folder>` (with `CLAUDE_CODE_EXECPATH` set
to the desktop-bundled Claude Code, or `--claude <claude.exe>`). It adds the marketplace, installs
`architect@architect-local`, lists and details the plugin, checks that an unknown agent is refused
with `architect:sdd-conductor` among the available agents, and, while the profile is signed out,
starts `claude -p --agent architect:sdd-conductor` up to its init event (the session ends at
"Not logged in", cost 0). Pass when it prints `Functional check: PASS`.

## Timed part (P-01)

0. Not timed: open a new PowerShell 7 window, dot-source
   `scripts/manual/isolated-profile.ps1` (it prints the profile folder, the versions and
   `"loggedIn": false`), run `claude`, sign in with `/login`, quit. A sign-in is the tester's to do;
   never write a password, key or token in a file, record or transcript.
1. Start a timer when the README is opened (download time excluded).
2. In the same window, start `claude` and add the repository folder as a marketplace:
   `/plugin marketplace add <path-to-this-repository>`.
3. Install the plugin: `/plugin install architect@architect-local`; restart Claude Code if asked.
4. Check `/plugin` lists `architect` as installed.
5. In a new empty folder inside the profile folder: `git init`, then start
   `claude --agent architect:sdd-conductor`.
6. Run `/architect:init`, answer the constitution rounds with the recommended options, approve G0
   with `/architect:gate constitution`.
7. Run `/architect:new "Coupon codes"` then `/architect:ideate`; stop the timer at the first
   interview question.

## Pass when

- The functional part prints `Functional check: PASS`.
- Step 4 shows `architect` installed (from the `architect-local` marketplace).
- Step 5 starts the conductor (its first reply orients on the workspace or proposes
  `/architect:init`).
- The time from step 1 to step 7 is at most 15 minutes (C001-NFR-602).

## Record

Date, Windows build, Claude Code and Node versions, the profile folder, elapsed time, any README step
that was unclear (verbatim note), pass/fail, and the caveat above. Add the record to `docs/dogfood.md`.
