# C001-TC-1102 — marketplace install on Windows 11 (manual, timed)

Verifies C001-TS-1102 (C001-AC-1102.1, C001-REQ-1102) and gives the timing of C001-NFR-602 (time to
first change ≤ 15 minutes).

- **Executor:** P-01 (or a P-03 adopter), with the README of C001-T-062.
- **Environment:** REF-WIN, a **fresh Windows 11 user profile** with Claude Code ≥ 2.1.295 and
  Node ≥ 20 installed; this repository available as a local folder (or a clone).

## Procedure

1. Start a timer when the README is opened (download time excluded).
2. In a terminal of the fresh profile, start `claude` and add the repository folder as a
   marketplace: `/plugin marketplace add <path-to-this-repository>`.
3. Install the plugin: `/plugin install architect@architect-local`; restart Claude Code if asked.
4. Check `/plugin` lists `architect` as installed.
5. In a new empty folder: `git init`, then start `claude --agent architect:sdd-conductor`.
6. Run `/architect:init`, answer the constitution rounds with the recommended options, approve G0
   with `/architect:gate constitution`.
7. Run `/architect:new "Coupon codes"` then `/architect:ideate`; stop the timer at the first
   interview question.

## Pass when

- Step 4 shows `architect` installed (from the `architect-local` marketplace).
- Step 5 starts the conductor (its first reply orients on the workspace or proposes
  `/architect:init`).
- The time from step 1 to step 7 is at most 15 minutes (C001-NFR-602).

## Record

Date, Windows build, Claude Code and Node versions, elapsed time, any README step that was unclear
(verbatim note), pass/fail. Add the record to `docs/dogfood.md`.
