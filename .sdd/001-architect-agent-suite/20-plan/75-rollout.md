# CHG-001 — Rollout, migration and rollback

## 1. Release model

- Distribution: the local marketplace in this repository (`.claude-plugin/marketplace.json`).
  Installed on P-01's machine only. No public publishing and no push in this change
  (OQ-18, Spec-Q4).
- Versions: `0.0.x` during M-1 … M-6 (development installs), `0.1.0` at the release gate
  (T-072), tagged locally as `v0.1.0`.
- Release notes: `CHANGELOG.md` (T-072).

## 2. Migration

| Step | What | Task |
|---|---|---|
| MIG-1 | This repository's hand-made `.sdd/` (bootstrap) is adopted by the CLI: `generator` updated, approvals and gate logs preserved (C001-REQ-123) | C001-T-013, C001-T-028 |
| MIG-2 | Prototype outputs (`80-traceability.md`, `85-open-items.md`) regenerated by `sdd trace`; prototypes deleted | C001-T-023, C001-T-028 |
| MIG-3 | `_constitution/` created for this repository, carrying DOD-G-01 … 07 | C001-T-070 |

## 3. Feature flags

None. Optional behaviour is controlled by tool detection (toolchain.md) and profiles, not
flags. Hooks can be switched off as a whole by disabling the plugin (RB-002).

## 4. Rollback

| ID | Situation | Steps | Linked |
|---|---|---|---|
| C001-RB-001 | A new plugin version misbehaves | Reinstall the previous version: check out the previous tag/commit of `plugins/architect`, rebuild, reinstall from the local marketplace | C001-T-072, C001-M-6 |
| C001-RB-002 | A guard blocks legitimate work | Disable the plugin (`/plugin disable architect`), continue the work, raise a defect against C001-REQ-1103 or 1106 | C001-T-050, C001-T-051 |
| C001-RB-003 | A CLI command corrupts `.sdd/` state | Restore `.sdd/` from git (`git checkout -- .sdd`), then run `sdd status --write` | C001-T-011, C001-T-017 |
| C001-RB-004 | An archive merge is wrong | Revert the archive commit; the change folder returns from `_archive/` with its approvals | C001-T-053, C001-T-075 |

## 5. Communication

The only user is P-01. Status is communicated through the session-start brief (from T-052),
`docs/dogfood.md`, `docs/nfr-results.md` and the release evidence file.
