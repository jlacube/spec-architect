# C001-IF-08 — Plugin layout, manifests and structure checks

## §1 Repository and plugin tree

```text
<repo>/
├── .claude-plugin/marketplace.json        local marketplace (C001-REQ-1102)
├── plugins/architect/                     the plugin root (${CLAUDE_PLUGIN_ROOT})
│   ├── .claude-plugin/plugin.json
│   ├── agents/sdd-*.md                    10 agents (C001-IF-09)
│   ├── skills/<name>/SKILL.md (+ references/)
│   ├── commands/*.md                      /architect:* (C001-IF-10)
│   ├── hooks/hooks.json                   (C001-IF-07)
│   ├── .mcp.json                          context7, deepwiki, serena (C001-REQ-1108)
│   ├── scripts/sdd.mjs                    bundled CLI (generated by the build)
│   ├── templates/                         artifact templates (full and lite)
│   ├── LICENSE, README.md, THIRD_PARTY_NOTICES.md
├── src/                                   CLI sources (bundled into scripts/sdd.mjs)
├── tests/                                 unit tests, lint fixtures, guard corpus, secrets fixtures
├── evals/                                 delegation and injection eval suites
├── bench/                                 NFR benchmarks
├── .github/workflows/check.yml            dormant matrix (C001-REQ-1119)
├── package.json                           scripts: build, test, check; devDependencies only
├── LICENSE, README.md                     (repository copies or links)
└── .sdd/                                  this project's own SDD workspace
```

Placing the plugin under `plugins/architect/` keeps development files (sources, tests,
`.sdd/`) out of the installed plugin.

## §2 Manifests

`plugins/architect/.claude-plugin/plugin.json`:

```json
{ "name": "architect", "version": "0.1.0", "description": "Spec-driven development agents: ideation → specification → planning with gates", "license": "MIT", "author": { "name": "<copyright holder>" } }
```

`.claude-plugin/marketplace.json` (repository root):

```json
{ "name": "architect-local", "owner": { "name": "<copyright holder>" }, "plugins": [ { "name": "architect", "source": "./plugins/architect", "description": "Spec-driven development agent suite" } ] }
```

Exact field names follow the Claude Code plugin documentation at build time [VERIFY S-05];
`claude plugin validate` is authoritative (C001-REQ-1117).
