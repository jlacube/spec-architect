# C002-T-079 — Fix for revisions D-051 … D-053: Copilot install notes and README section

## Intent

The install notes of the Copilot package (`plugins/architect/targets/copilot/install.md`, generated as
`INSTALL.md`) are out of date on VS Code 1.145.2 (defects D-051 … D-053; digest facts 2, 3, 6 … 8 and
the P-01 decision on D-052). This task brings them, and the Copilot VS Code section of the plugin
README, to the revised C002-REQ-304, C002-IF-005 §5 (steps 4 … 8 and item 9, `chat.autoReply`) and
C002-TS-306, and to the revised C002-REQ-305 and C002-TS-307 (the README states the known limitation
and links its statement in the install notes; critic CR-159).

## Targets

| Kind | Target | Change |
|---|---|---|
| modify | `plugins/architect/targets/copilot/install.md` | (1) slash commands are `/architect:<name>` (for example `/architect:init`, `/architect:new`, `/architect:doctor`); a bare `/init` runs VS Code's built-in `/init`, which writes `AGENTS.md` or `.github/copilot-instructions.md`, so use `/architect:init`; (2) pick a model in the chat's model picker in every new window: a new window starts on "Auto", which routes to another model; the reply footer names the model that answered (the models statement of C002-TS-306); (3) the workspace MCP servers start when one of their tools is first used, not after the first message; (4) **known limitation** (D-052, P-01's decision of 2026-11-11): VS Code 1.145.2 sends no `agent_type` to PreToolUse hooks, so the subagent guard hook does not stop a subagent that is not an Architect agent (for example one that the user's own default agent starts) in a repository with `.sdd/`; the Architect boundary on VS Code rests on the specialists' tool lists, the conductor delegating only to the nine specialists and the sdd MCP server guard; the Copilot hooks fallback (`copilot-hooks`) gives no guard on VS Code 1.145.2 and is not offered for VS Code; (5) `chat.autoReply` (C002-IF-005 §5 item 9, C002-TS-306): keep it off; when it is on, VS Code answers the conductor's questions itself with its auto-reply text, which the conductor takes as no answer, so no round or gate goes forward; `chat.tools.global.autoApprove` approves tools only and does not answer questions |
| modify | `plugins/architect/README.md` › "Copilot VS Code" | the sentence on the subagent guard hook states the known limitation of item 4 (PreToolUse input without `agent_type` on VS Code) and links its statement in the install notes, as the revised C002-REQ-305 and C002-TS-307 require (critic CR-159) |
