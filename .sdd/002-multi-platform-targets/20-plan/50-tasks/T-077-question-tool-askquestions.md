# C002-T-077 — Fix for revision D-051: the question tool askQuestions beside ask_user in the Copilot package

## Intent

In the T-050 findings pass of 2026-11-11 (VS Code 1.145.2, Copilot Chat 0.73.0, Local session type)
the conductor had no question tool: VS Code's tool is `askQuestions` (`vscode_askQuestions`), while
the package grants only `ask_user`, a Copilot CLI tool, so every round fell back to plain text
(defect D-051; `../revision-D051-D053-digest.md` facts 1 and 2). This task maps `AskUserQuestion` to
both tools, names both in the generated body text, and writes the `askQuestions` input and result
shape and the no-answer rule (the host's auto-reply text included) into the Copilot interview and
gate wiring. One Copilot CLI session shows that Copilot CLI accepts the extra name in an agent's
`tools` list. The Claude Code text stays unchanged (C002-CON-10).
