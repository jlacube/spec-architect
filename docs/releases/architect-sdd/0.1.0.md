## Deviations from the step outline

1. **Path form.** Step 4 writes `npm publish dist/architect-sdd-0.1.0.tgz`. npm reads a path without
   `./` as a GitHub shorthand (`dist/<repo>`) and fails with `Permission denied (publickey)`. The working
   command is `npm publish ./dist/architect-sdd-0.1.0.tgz`. The same form appears in C002-ADR-004; both
   are in the approved CHG-002 plan and were not edited. The runsheets and
   `docs/release-procedure-0.1.0.md` are corrected.
2. **2FA and staged publishing.** The first corrected attempt returned E403 ("Two-factor authentication
   or granular access token with bypass 2fa enabled is required"), under npm's 2026 publishing policy.
   After P-01 enabled interactive 2FA, the registry staged the publication of this new package: it
   first published the placeholder `architect-sdd@0.0.0-stage` (2026-11-15T23:04:56Z, 335 B, no
   content), then made 0.1.0 public on approval (P-01: "approved / staged automatically"). The local npm
   was 10.9.8, which has no `npm stage` command (npm 11.15 or later). The placeholder stays in the
   version list; `latest` points to 0.1.0.
